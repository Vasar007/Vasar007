# Vasily Vasilyev

I'm a backend developer working mainly in C# and .NET, with smaller projects in F# and C++.

**What I work with:** C# and .NET, F#, C++, Python; some Java and JavaScript; CI/CD via GitHub Actions and AppVeyor; NuGet packaging.

## Projects

- **[ProjectV](https://github.com/Vasar007/ProjectV)**
  - Automatic evaluation of movies, games and books against popular rating databases.
  - C# and F# on .NET: a desktop client, a Telegram bot and a console client, documented on a public GitHub wiki.
  - Apache-2.0 licence.
- **[Acolyte.NET](https://github.com/Vasar007/Acolyte.NET)**
  - A helper library of extension methods for everyday .NET code.
  - Published as a NuGet package, with AppVeyor CI on two branches and FOSSA licence scanning.
  - Apache-2.0 licence.
- **[TIMLE](https://github.com/Vasar007/TIMLE)**
  - A 2D platformer, "This Is My Last Escapade".
  - Built in C++ with SFML.
  - Apache-2.0 licence.
- **[cx_matrix](https://github.com/Vasar007/cx_matrix)**
  - Compile-time matrix math in C++17 via `constexpr`.
  - Single-header library plus a CMake build, with correctness demonstrated on Compiler Explorer.
  - Apache-2.0 licence.
